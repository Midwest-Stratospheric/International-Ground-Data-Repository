# Data Sources

This directory documents the public data sources curated into the International Ground Data Repository.

## Primary Source: NOAA IGRA

- **Full name**: Integrated Global Radiosonde Archive (IGRA) Version 2.2+
- **Provider**: NOAA National Centers for Environmental Information (NCEI)
- **Coverage**: >2,800 stations historically; ~800–900 updating near-real-time daily
- **Variables**: Pressure, temperature, geopotential height, relative humidity, dewpoint depression, wind direction & speed, tropopause info
- **Access**:
  - Landing page: https://www.ncei.noaa.gov/products/weather-balloon/integrated-global-radiosonde-archive
  - Bulk HTTPS downloads available
  - FTP: ftp.ncei.noaa.gov/pub/data/igra/
- **Update frequency**: Daily for recent soundings

## Other Sources (planned / partial)

- Global BUFR upper-air streams from NWS TG
- Copernicus CUON (Comprehensive Upper-air Observation Network)
- Free University of Berlin / KIT QBO tropical zonal winds
- Satellite-homogenized products (SWOOSH, etc.) where openly available
- Regional open radiosonde networks (where licensing permits)

All original data remains under the terms of the respective providers. This repository provides indexes, curated samples, and persistent links.
