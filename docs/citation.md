# How to Cite Data from IGDR

1. Always cite the original data provider first (usually NOAA NCEI IGRA).
2. Then acknowledge Midwest Stratospheric Data Systems and this repository as the curation layer.

## Recommended IGRA Citation

Durre, Imke; Yin, Xungang; Vose, Russell S.; Applequist, Scott; Arnfield, Jeff; Korzeniewski, Bryant; Hundermark, Bruce. (2016) Integrated Global Radiosonde Archive (IGRA), Version 2. NOAA National Centers for Environmental Information. DOI:10.7289/V5X63K0Q [access date].
