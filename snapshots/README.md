# Daily Snapshots

This directory holds daily curated indexes and lightweight snapshots of global upper-air / stratospheric observation availability.

Each subdirectory is named `YYYY-MM-DD` and may contain:
- Station activity summaries
- Links to latest available soundings
- Sample profiles or aggregated statistics
- Machine-readable catalogs (JSON/CSV)

Full bulk data remains at the authoritative NOAA/NCEI and other source archives. These snapshots exist to provide a stable, versioned view of what was publicly available on a given day and to support long-term reproducibility.

Automated daily updates will populate new dated folders.
